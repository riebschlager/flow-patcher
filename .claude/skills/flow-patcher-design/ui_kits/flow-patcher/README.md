# Flow Patcher UI kit

Click-through recreation of the editor built only from the component library.

- **Patch view:** the example graph "Euclidean drums that stir the fluid" plus pointer chords. The clock runs at 112 BPM, so Euclidean hits fire their cables and LEDs. Click a node to select it. Drag param fields. Press Tab or double-click the canvas for the node palette. The crosshair toggles the probe.
- **Play view:** the full-window canvas with the pinned-knob strip. "Brightness" is the same parameter as Sampled Voice › Cutoff.

The fluid render is a placeholder gradient.
